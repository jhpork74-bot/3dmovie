# 전체 요구사항 · 완료 기준

완료 상태는 PROJECT_STATUS.md와 각 모듈의 capabilities로 판단한다. 화면/버튼만으로 실제 모델 기능이 완료됐다고 말하지 않는다.

1. 웹 브라우저에서 사용. 장기 확장 가능한 PD 제작 스튜디오 베이스와 독립 기능 모듈.
2. 배경 영상 불러오기, 속도/확대/축소/줌·팬 타임라인. 배경 효과 위쪽.
3. 기본 제공 이모지, PNG/JPG/JPEG/WebP/SVG/GIF 교체(애니메이션 GIF는 첫 프레임), 실제 파일 해독 확인.
4. 이모지 1~5개 동시 배치, 각각 마우스 크기/위치 조절. 기본 200×200px 우측 아래. 이모지 효과 아래쪽.
5. 밝고 귀여운 한국어 합성 음성, 사용자가 읽기 속도 조절.
6. 발음에 맞는 **정밀** 립싱크. 음성 크기로 여닫는 기본형을 대체품으로 제공하지 않음.
7. 대본 내용과 매칭되는 웃음·슬픔·눈물 등의 얼굴 감정 렌더링. 분석 결과와 렌더링 결과를 구분.
8. `이모지1: 안녕` 형식의 티키타카. 실제 TTS 길이로 순차 배치, 또는 대사별 시작 초 직접 지정/타임라인 드래그. 같은 화자 겹침 검사.
9. 정밀 AI는 무료 클라우드만 사용. 유료 서비스 자동 전환 금지. 무료 GPU의 할당/지속시간 보장 금지.
10. 전체 5구간 게이지를 대본 입력창 바로 위에 표시. 작은 처리 단위 완료물을 보관하고 합치기.
11. 자동시작 기본 체크, 연결 회복 확인 후 미완료 부분 재개. 중단/재개 시각·실측 기반 남은 시간·다음 확인 카운트다운. 무료 GPU 배정 예정시각은 모르면 미정으로 표시.
12. 모든 구간 완료 후 자동 합치기·인코딩·사용자가 지정한 위치 저장. PC 오프라인이면 서버/Drive 결과 보관 후 다시 연결해 다운로드.
13. 실행/접속 시 저장 폴더 선택 안내. 브라우저 권한은 사용자 클릭으로 요청. 폴더 핸들은 IndexedDB, 표시 이름은 INI에 저장. 미지원 브라우저 다운로드 대체.
14. INI에 일반 설정 일원화. 설정창에서 저장/불러오기. 글꼴·글자색·배경색·저장 위치·각 편집/계정 설정. 인증 코드는 비공개 보관.
15. MP3/WAV/M4A/AAC/OGG/FLAC, AVI/MP4/MOV 등의 오디오 추출로 BGM 가져오기. 볼륨/대사 중 자동 낮추기.
16. 로컬 합성 효과음(알림/팝/전환) 추가·시간·볼륨·삭제.
17. Vegas9 작업 흐름의 FX 목록·미리보기·세부값. 페이드/색감/흑백/흐림/선명도/비네트, 줌 키프레임.
18. Flash CS5 영감의 중앙 무대·왼쪽 도구·오른쪽 속성·아래 레이어. Adobe/Sony의 독점 자산/코드 복제 불필요.
19. 한 장 또는 순서별 여러 사진에서 한국어 대본 자동 작성. 사진 순서 조절·주제/말투·초안 수정·대본 적용.
20. AI 자막 달기: 기존 배경 음성 인식, 언어·용어집, 검토 필요 항목, 시간/내용/스타일 직접 수정, SRT 및 영상 삽입.
21. 유튜브1920×1080, 쇼츠/틱톡1080×1920 30fps 프리셋, H.264/AAC·선택AV1, 투명WebM 알파.
22. 계정 표시명/아이디 저장. 게시하기는 저장 후 유튜브/틱톡 업로드 페이지 또는 인스타 홈페이지 연결. 현재 자동 OAuth 로그인/직접 업로드 구현과 혼동하지 않음.
23. 개발 중단 전 GitHub 3D프로그램 폴더 업데이트, 요구/검사/미완료/다음 작업 기록. 다음 “3D프로그램” 요청 시 재개.
24. 최종 전체 프로그램을 ZIP으로 제공. 중간 백업과 완성 배포 구분.
