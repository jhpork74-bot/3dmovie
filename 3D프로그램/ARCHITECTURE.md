# 모듈형 웹 제작 스튜디오

공통 코어는 프로젝트/미디어 참조, INI 설정, 작업 수명주기/취소/완료물, 타임라인과 내보내기 규약을 맡는다. 기능별로 UI 패널, 입력 스키마, 실행 단계, 결과 스키마, 캐시 키/버전, 테스트를 정의한다.

`core/modules.js`가 모듈 id/version/requires/status를 등록하고 의존성 순서를 검사한다. 기능을 새로 만들 때 전체 컨트롤러를 조건문으로 확장하는 대신 독립 도메인 모듈과 API 어댑터를 추가한다. 현재 초기 구현에는 큰 컨트롤러가 남아 있으므로 기능별 분할을 이어가야 한다.

현재 도메인 모듈: 설정(settings-store), 대사(story), 효과(effects), 자막(subtitles), 미디어(media), 장면 합성(scene), 클라우드 통신(cloud-lipsync). 브라우저 브리지(ui/web-bridge)는 렌더러와 전송 방식을 분리한다. Electron 어댑터는 레거시이며 웹 UI와 분리 유지한다.

무료 Colab 세션에서 CPU 웹 서버/FFmpeg/TTS와 GPU 모델 서버를 별도 프로세스로 실행한다. 사용자 Google Drive의 비공개 프로젝트 디렉터리에 완료 단위와 결과를 저장해야 세션 종료를 견딘다. 현재 영구 Drive 연결 노트북은 아직 완성되지 않았다.

비동기 웹 작업은 제출 id → 상태/실측 진행 → 결과 수신으로 처리한다. 네트워크 실패 때문에 같은 실행을 무작정 중복 제출하지 않는다. 완료된 작업 단위만 원자적으로 확정하고, 연결 회복 후 미완료부터 재개한다. 모델이 주지 않는 퍼센트나 GPU 재배정 시각을 만들어내지 않는다.

새 기능 추가 체크: (1) 레지스트리와 요구사항 (2) INI/프로젝트 스키마 마이그레이션 (3) 순수 도메인 로직 (4) 웹 API/작업 처리 (5) UI 패널/타임라인 (6) 의미 있는 단위/통합 검사 (7) capability 상태와 작업 기록 갱신.
