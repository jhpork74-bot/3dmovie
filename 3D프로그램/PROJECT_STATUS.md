# 3D프로그램 · 웹 PD 제작 스튜디오 (개발 중)

이 파일은 새 세션에서 재개하기 위한 기준입니다. **완성본이 아닙니다.** 사용자가 “3D프로그램” 또는 “3D프로그램 이어서 개발해줘”라고 하면 이 파일, REQUIREMENTS.md, ARCHITECTURE.md를 먼저 읽고 작업을 이어갑니다. PC가 꺼져 있거나 채팅이 종료된 동안 AI가 자동으로 며칠간 개발한다고 약속하지 않습니다.

## 최종 방향

- Windows 설치형에서 **웹(Web)** 방식으로 전환. 공통 베이스에 기능 모듈을 추가하는 장기 개발 프로젝트.
- 용도: 사회복지사의 사회공헌 활동 사진을 활용한 유튜브·쇼츠 제작, 여러 3D 스타일 이모지의 대화로 차별화.
- 사용자 PC: Windows 10, GTX 960 전용 메모리 약 2GB. 정밀 AI 처리는 **무료 클라우드만** 허용. 유료 API/유료 GPU로 자동 전환하지 않음.
- UI 담당은 별도 에이전트가 구현. Claude 연결 도구는 없으며 Claude가 실제 작업했다고 말하지 않음.

## 현재 구현·검증

- Flash CS5 영감의 회색 무대·도구막대·속성·레이어 화면과 Vegas9 스타일 FX 창.
- 여러 이모지 이미지 선택·복원·마우스 크기/위치 조절, 대사 시작점/드래그 타임라인, 감정 분석 선택.
- 5개 진행률 게이지, 자동시작 기본 체크, 중단·재개 시각/실측 기반 남은 시간/다음 연결 확인, 수동 중단 억제.
- INI 가져오기/내보내기, 글꼴·색·배경·저장 폴더, BGM·FX·사진 대본·자막 편집 UI.
- 실제 Chromium UI 테스트 8개 통과. 이는 모의 브리지/서버로 검사한 UI 동작이며 GPU AI 생성의 증거가 아님.
- 실제 로컬 한국어 TTS 생성, 1080p H.264/AAC·세로 AV1/AAC·알파 WebM 인코딩 검증.
- **로컬 기본형 입 움직임으로** 두 이모지 순차 대화 + 효과음 + 따뜻한 색감 + 자막을 포함한 1920×1080 장면 생성 성공. 정밀 립싱크나 감정 렌더링 성공으로 표현하지 말 것.
- 웹 서버/인증/미디어 업로드/비동기 작업/SSE/브라우저 저장 브리지 코드 작성. 실제 백엔드 통합 테스트 추가 필요.
- 무료 MuseTalk 서버와 Colab 설치 스크립트 작성. 현재 개발 환경에는 GPU가 없고 Hugging Face 접근도 차단되어 실제 모델 구동은 미검증.

## 반드시 남아 있는 일

1. 웹 서버 인증·업로드·설정·작업 API 실제 테스트. 누락 라우트/브리지 계약 검사. Node worker와 LD_LIBRARY_PATH 점검.
2. cloud/bootstrap.py와 cloud/server.py를 포함한 **실행 가능한 Colab 노트북** 완성. Google Drive를 명시적으로 연결해 체크포인트·최종 결과를 세션 종료 후에도 유지. 무료 GPU 할당/세션 지속은 보장하지 않음.
3. 실제 GPU에서 MuseTalk 설치·한 구간 생성·사용자 이모지 얼굴 인식·알파 복원·5구간/하위 단위 재개·합치기·다운로드를 검증.
4. 사진 대본 무료 비전 모델과 실제 연결. 현재 웹 photos/generate는 명시적인 미구현 오류를 반환함. UI는 사진 순서와 초안 편집만 구현됨.
5. Whisper 등 무료 ASR 연결 및 subtitles/transcribe 라우트 구현. 자막 UI/ASS 영상 삽입은 있지만 원본 음성 자동 인식은 미연결. 원본 음성/문맥/용어집을 사용하고 인터넷의 다른 음성을 근거로 원문을 지어내지 않음.
6. **대본에 맞춘 웃음·눈물·눈썹 등 감정 렌더러 미구현**. MuseTalk는 정밀 입 모양 엔진이지 전체 감정 엔진이 아님. 현재 한국어 키워드 기반 감정 분석만 있음. renderScene 결과는 emotionRendering:'not-implemented'를 반환함.
7. 자막은 원본 영상 시각 기준. videoSpeed에 따른 자막 변환과 UI 미리보기 시간축 일치 검사. 배경 원음 보존/ASR 자막만 생성하는 흐름을 최종 정책으로 확정.
8. 대사/여러 이모지/배경음/효과/자막을 조합한 전체 통합 검사. 브라우저 닫힘·Colab 종료·새 세션 URL 변경 후 복구 검사.
9. 사용자 요구 전체를 포함한 최종 웹 ZIP과 실행 설명서 작성. 중간 백업은 최종 완성본으로 표현하지 않음.

## GitHub/개인 파일

사용자가 jhpork74-bot/3dmovie 저장소의 **3D프로그램** 폴더에 최신 소스와 작업 기록을 중단 전에 업로드하도록 명시적으로 요청함. 강제 푸시는 하지 않음. 원본 개인 사진/영상, 연결 코드, 실제 설정/생성 캐시는 공개 소스에 포함하지 않음. 기본 개인 이모지는 현재 로컬/개인 미디어에 유지하고 새 공개 체크아웃에서는 중립 샘플을 생성하거나 직접 가져오도록 안내.

## 주요 파일

- web-server.js: 인증·미디어·설정·비동기 웹 API
- core/modules.js: 기능 모듈 등록/의존성/능력 상태
- settings-store.js: INI 형식과 정규화
- engine.js: 한국어 TTS, 클라우드 하위 단위/완료 캐시, 알파 복원
- scene.js: 다중 화자 스케줄, 이모지·BGM·SFX·FX·자막 합성
- story.js / effects.js / subtitles.js / media.js: 독립 도메인 모듈
- cloud-lipsync.js: 본인 무료 세션과 통신, 취소/결과 수신
- cloud/: 무료 GPU 설치/작업 서버 (실행 검증 전)
- ui/: 화면·웹 브리지·UI 도메인 도구
- test/: 단위·Chromium·웹 브리지 검사

초기 desktop main.js/preload.js/Launch.cmd는 전환 전 코드이며 현재 최종 배포 목표가 아님.

## 단일 HTML 미리보기 추가

`index.html`은 CSS/스크립트/중립 샘플 이모지를 포함한 단일 파일 화면 미리보기. `index-preview.zip`을 풀어 index.html을 열면 된다. 실제 AI 생성·서버 저장은 연결되지 않으며 완성 앱으로 안내하지 않는다. Chromium에서 외부 리소스 없이 화면 로딩·설정창 열기·JavaScript 오류 없음 확인.

## 연결 시작 파일 / 무료 Colab 실행 초안

- `index.html`은 이제 ZIP의 `ui/index.html`로 연결하는 시작 파일이며, 서버 주소 입력란도 제공. 이전 단일 파일 미리보기는 `preview.html`로 보존.
- `EmojiStudio-Linked.zip`에 UI·소스·중립 샘플·Colab 노트북을 함께 넣는 빌더 추가. 개인 사진/영상/연결 코드는 제외.
- `cloud/colab_launch.py`는 무료 GPU 모델 환경 설치 후 별도 Node 웹 서버와 GPU 작업 서버를 실행하고, 검증한 cloudflared 다운로드로 인증된 웹 주소를 표시. 코드가 작성된 것이며 **실제 Colab/GPU 구동은 아직 미검증**.
- 사용자의 Google 로그인·무료 GPU 배정·Drive 동의가 필요하며 에이전트가 대신 할 수 없음. Node의 SIHU_DATA_DIR를 개인 Drive로 지정해 완료 파일 보존을 준비하지만, 세션 종료/재개 전체 검증은 미완료.

연결 패키지 검사: ZIP 무결성, 11개 필수 파일, Colab 코드 셀 4개의 문법 확인. 압축 해제본 index → ui/index 이동과 CSS/JS 6개 로드 및 JavaScript 오류 없음 확인. 이 UI 연결 검사에서는 백엔드 설정 응답을 모의 제공했으며 실제 무료 GPU는 검증하지 않음.
