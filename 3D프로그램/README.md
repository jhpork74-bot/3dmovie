# 이모지스튜디오 · 웹 PD 제작 스튜디오

**개발 중간 체크포인트입니다. 최종 완성본이 아닙니다.** 전체 요구와 재개 순서는 REQUIREMENTS.md, PROJECT_STATUS.md, ARCHITECTURE.md를 확인하세요.

프로그램은 웹 방향으로 전환했습니다. Flash CS5 영감의 무대/레이어 편집과 Vegas9 방식의 효과 선택을 참고하며, 사회복지사의 사회공헌 사진을 여러 이모지의 대화·자막·배경음과 결합하는 용도입니다. 기능은 공통 프로젝트·설정·작업 코어에 모듈로 연결합니다.

## 현재 검사

2026-11-16 기준 `npm test` **13개 통과**: 도메인 단위 검사와 Chromium UI/모의 웹 브리지 검사. 실제 TTS·FFmpeg로 기본형 입 움직임의 2인 대화·효과음·색감·자막 합성도 확인했습니다. 이것은 정밀 GPU 립싱크, 감정 표정 생성, 사진 AI 대본, 음성 자동 자막의 성공 검증을 뜻하지 않습니다.

## 개발 실행

Node.js 22 이상, FFmpeg(libx264/libvpx-vp9/libass 등)가 필요합니다.

```sh
npm ci --ignore-scripts
node scripts/ensure-assets.js
npm test
```

웹 서버는 `SIHU_SESSION_TOKEN`에 본인 세션의 무작위 연결 코드(24자 이상)를 안전하게 설정한 후 `npm start`로 실행합니다. 코드 값을 공개 소스나 INI에 넣지 마세요. Node 서버는 기본적으로 127.0.0.1:3000에 바인딩되며, 실제 서비스에서는 본인 인증이 적용된 HTTPS 연결이 필요합니다. 저장 경로는 `SIHU_DATA_DIR`로 지정합니다.

무료 GPU 모델 서버는 같은 머신의 127.0.0.1:7860을 사용하며 별도 인증 코드를 적용합니다. `cloud/server.py`와 `cloud/bootstrap.py`는 작성되어 있으나 실제 무료 Colab GPU 실행과 영구 Drive 복구는 아직 검증 전입니다. 완성된 사용자용 노트북도 남은 작업입니다. 유료 API로 자동 전환하지 않습니다.

TTS의 한국어 모델은 원본 sherpa-onnx 릴리스의 `vits-mimic3-ko_KO-kss_low.tar.bz2`를 받아 `vendor/korean`에 풀어야 합니다. 모델과 FFmpeg 바이너리는 이 소스 저장소에 포함하지 않습니다. 출처/라이선스는 THIRD_PARTY.md에 기록합니다. Linux에서는 native module 디렉터리를 LD_LIBRARY_PATH에 포함해야 합니다.

## 개인 미디어와 설정

원본 개인 사진/영상·사용자 이모지·연결 코드·실제 INI·음성/완료 캐시는 공개 GitHub에 올리지 않습니다. 새 체크아웃에서는 중립 샘플을 만들고 본인 이모지를 직접 가져오세요. 현재 작업 환경의 개인 기본 이모지는 별도로 유지합니다.

브라우저에서 지정한 폴더는 Chrome/Edge의 사용자 클릭과 쓰기 권한이 필요합니다. 폴더 핸들은 IndexedDB, 표시 이름과 일반 설정은 INI에 보관합니다. 브라우저가 닫혔을 때도 서버가 살아 있으면 작업은 계속될 수 있으나, 무료 Colab 세션이 계속 살아 있다는 보장은 없습니다. 영구 Drive 체크포인트 구현/검증 전에는 세션 종료 후 복구가 완성됐다고 안내하지 마세요.
